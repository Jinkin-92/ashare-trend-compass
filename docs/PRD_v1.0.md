# A-Share Trend Compass（A股趋势罗盘）产品需求文档 v1.0

> 基于《趋势交易工具_PRD_v0.3.md》重新整理，用于指导本地化 MVP 开发。

---

## 1. 产品定位

本地部署的 A 股趋势交易决策辅助工具，服务“顺势交易者”，解决两个问题：

- **什么时候动手**（择时） → 趋势温度
- **动哪个品种**（选筹） → 趋势相对强度

## 2. 覆盖范围

- **只做 A 股**：全市场个股、一级/二级行业、概念板块、主要宽基指数。
- **不做跨资产比较**：根节点直接是“A股”，不向上比较黄金/楼市/债市。
- **每日盘后更新一次**，日线级别。
- **本地部署**，数据隐私可控。

## 3. 非目标

- 不做自动交易执行，不接入券商下单接口。
- 不提供个股基本面分析。
- 不构成投资建议，产品内需展示免责声明。

## 4. 核心指标

### 4.1 趋势温度（Trend Temperature）

日线级别，七档分类：沸 / 热 / 温 / 平 / 凉 / 寒 / 冻。

由三个维度组合决定：

1. **趋势方向分**：价格相对 MA60 的位置 + MA20 与 MA60 的排列关系。
2. **动量分**：多周期 ROC 加权（如 20/60/120 日），近期权重更高。
3. **波动扩张分**：短期 ATR / 中期 ATR 均值，区分温和趋势与极端行情。

### 4.2 趋势相对强度（Trend Relative Strength）

- 维护分类树（node_type：index / industry_l1 / industry_l2 / concept / stock）。
- 每个节点计算加权收益率。
- **按 node_type 全局排名**，转换为 1–99 百分位分数。
- 保存 N 日前排名，计算强度趋势箭头：↑ / ↓ / ↓↓ / flat。

### 4.3 右侧状态机（Hysteresis）

- 多头右侧：首次进入需温度 ≥ 热（含沸），维持阈值 ≥ 温；跌破温退出。
- 空头右侧：首次进入需温度 ≤ 寒（含冻），维持阈值 ≤ 凉；升破凉退出。
- 右侧天数按自然日递增，退出清零；UI 中高亮右侧行。

### 4.4 分类体系

- **MVP 采用方案 A**：使用 akshare 自带的标准分类（申万/东财），零维护成本。
- **V2 再评估方案 B**：是否手工维护 16 个主题分组映射表。

## 5. 功能需求

### P0

1. **总览仪表盘**：七档温度分布柱状图/饼图；行业温度热力图。
2. **品种列表**：
   - 可折叠分类树 + 全部展开长列表。
   - 字段：名称/代码、最新价、日涨幅、成交额/流通市值、温度色块、近 3 月 sparkline、RS、收藏、右侧天数。
   - 右侧行高亮；涨红跌绿。
   - 排序：温度档、右侧天数、名称、流通市值、价格、日涨幅、成交额、RS。
3. **品种详情页**：对数坐标累计收益曲线 + 基准对比 + 右侧区间标黄 + 温度时间轴 + RS 走势。
4. **今日信号清单**：新增右侧、退出右侧。

### P1

5. **筛选器**：温度档位、RS 区间、领头羊筛选、反转埋伏筛选。
6. **自选池管理**：创建/编辑池，池内单独计算 RS 并提示当前排名范围。

### P2

7. **静态快照导出**：长图 PNG，便于公众号/复盘分享。
8. **信号推送**：复用 DSA 飞书/微信机器人做每日盘后推送。
9. **主题分组映射**：可选的 16 个自定义主题分组。

## 6. 技术架构

- **数据管道**：Python 批处理，每日盘后运行一次。
- **数据源**：DSA `stock_daily` 只读 + akshare 行业/概念/指数。
- **存储**：本地 SQLite（`data/trend_compass.db`）。
- **前端**：静态 HTML + 原生 JS + ECharts，直接读取 `web/data/*.json`。
- **不引入常驻后端服务**。

## 8. 成功标准

- 数据管道分钟级跑完全市场。
- 温度/RS/右侧状态每日更新。
- 前端无需后端即可展示列表、详情、仪表盘。
- 算法校准：温度档位一致率 ≥ 85%，RS 平均误差 ≤ ±5。
