## 3. 修复后右侧状态机语义

按 Jinkin 文档的"高考"比喻：
- **趋势温度 = 考试分数**（沸/热/温/平/凉/寒/冻）
- **趋势相对强度 = 年级排名**（1-99 分位）
- **右侧 = 模拟考到"985 分数线"且后续每次都没掉到"非 985"分数**

具体定义：
| 状态 | 含义 | 在右侧？ |
|---|---|---|
| 沸 | 模拟考 ≥ 985 + 极高分 | ✅ 右侧 |
| 热 | 模拟考 ≥ 985 分数线 | ✅ 右侧 |
| 温 | 模拟考接近 985 但还没到 | ❌ 准右侧（不算） |
| 平 | 模拟考不达 985 | ❌（退出） |
| 凉/寒/冻 | 模拟考低于 985 区间 | ❌ |

**进入**：当前非右侧 + 温度转"热"或"沸" → 右侧天数=1
**维持**：已在右侧 + 温度保持"热"或"沸" → 天数+1
**退出**：已在右侧 + 温度回"温"或"平"或以下 → 天数清零
**说明**：温不算退出边界（"未回到平及以下则右侧没破坏"，意思是温→凉才算破坏），但温也不算正式右侧——**进入时跳过温**（温转热才进）、**退出时也跳过温**（温转平才算退）

按这个语义修正算法（详见 `src/indicators/right_side.py`）。
