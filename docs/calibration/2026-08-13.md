## 收敛性判断

1. **新 3 日（08-10 / 08-12 / 08-13）一致率稳定在 86.3% / 90.2% / 90.2%，±1档 98.0% / 98.0% / 100.0%，signed 均值 -0.16 / -0.04 / -0.06**——三日高度一致，阈值已经稳定收敛到「本地几乎无系统偏差」的状态。
2. 旧 5 日偏差是温度语义不同（旧图默认档偏"温"、新图默认档为"平"）造成的不可同日比较，不是阈值问题。
3. **pooled 8 日 48.1% / 81.8% / -0.37** vs 08-12 校准时 7 日 42.9% / 79.9% / -0.41：略好（+5% 一致、+2% ±1档、+0.04 signed），纯粹是新增一日 90% 把平均拉高了，阈值本身未变。
4. 已知结构性问题（医疗服务顶层偏快、医药健康顶部响应慢）已超出阈值可解范围，需另寻方案。

## 过程中遇到的环境问题

1. L2 行业指数发布滞后（已知）：daily_update 在 17:10 跑完整管道时 `industries: 0`，L2 daily_price 仍停在 08-12；08-13 的 eval_multiday 第一次跑出来 88.2% 实际是「用截至 08-12 的数据预测 08-13」，不能算真实 08-13 校准。
2. 处理：手动 `DailyPriceSync.sync_industries(end_date=2026-08-13)` 补拉 155 条行业指数（耗时 2m47s，全部从 tinyshare 兜底，akshare `index_hist_sw` 当日仍未发布），然后 `recalc_temperature.py --days 7` 回灌 29727 行（耗时 8m18s），让 L2 daily_indicator 推进到 08-13。
3. 再跑 calib_compare 得到真实 08-13 一致率 90.2% / ±1档 100.0%。
4. 已知 RS 字段在 recalc_temperature 不写（只算温度），因此 RS 字段为 NULL——eval_multiday 仍能跑公式回放，与 DB 库存 RS 不冲突；这是设计隔离，不是 bug。

## 遗留

- 医疗服务顶层响应偏快：08-12 (温→沸) + 08-13 (热→沸)。连续两次超调 1 档。建议下次观察 08-14 是否同样，再决定是否引入「顶部阻尼」（如沸档需要连续 2 日维持才能记沸）或「顶层响应慢化」（在方向分不变情况下加大波动扩张权重）。
- 中药、化学制药与"平"边界模糊（score -3 到 +12），与已知结构性问题一致。参考"温"在该区间与"平"不可分，非阈值可解。
- 光伏风电、轨交军工小幅下跌品种被判凉，参考判平——我们对下跌品种打分更冷。这是「跌幅权重过强」的方向性问题，未来如要调整需重新校准多个变量，不在本次范围。
