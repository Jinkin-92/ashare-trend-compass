# 2026-08-05 温度校准记录

## 背景

使用 2026-08-04 截图（趋势动物 app，53 个品种）作为校准参考。
上一次校准基线 (08-03)：温度一致率 50%，±1档率 96.7%，RS 偏差 -8.0。

## 问题诊断

08-04 截图对比发现温度系统性偏冷：
- 一致率仅 16.3%，±1档率 46.9%
- 39/49 品种本地比参考冷，signed_mean = -1.49
- 根因：方向分使用 MA20/MA60，对短期反弹极度迟钝
  - 电子元件 ref=沸，本地 score=-24.6（价格低于 MA60 18%，direction 被 clip 到 -1.0）
  - 游戏 ref=沸，本地 score=-10.4（4天涨8.5%，但 direction 仅 0.137）

## 调参方案

通过 `scripts/optimize_params.py` 网格搜索 6 种参数组合 × 8 种阈值 × 3 种确认天数：

| 参数 | 旧值 | 新值 | 说明 |
|------|------|------|------|
| 方向 MA (long) | MA20/MA60 | **MA5/MA10** | 大幅提升对短期反弹的敏感度 |
| ROC 窗口 (long) | (20,60,120) | **(5,10,20,60,120)** | 增加 5日/10日短期动量 |
| ROC 权重分布 | linspace(0.5,0.2) | **linspace(0.5,0.1)** | 更偏向近期 |
| 方向分权重 | 20 | **12** | 降低方向分对总分的压制 |
| 动量分权重 | 0.7 | **1.0** | 提升动量贡献 |
| vol_adj 系数 | 8 | **4** | 减少方向极值时的惩罚 |
| EMA 平滑 | span=3 | **span=2** | 减少平滑延迟 |
| CONFIRM_DAYS | 2 | **1** | 状态机更快响应 |

### 新分档阈值

| 档位 | 旧阈值 | 新阈值 |
|------|--------|--------|
| 沸 | ≥ 50 | **≥ 35** |
| 热 | ≥ 25 | **≥ 10** |
| 温 | ≥ 3 | **≥ -12** |
| 平 | (-19, 3) | **(-34, -12)** |
| 凉 | (-50, -19] | **(-65, -34]** |

| 冻 | ≤ -80 | **≤ -95** |

## 残余偏差分析

- **3档偏差 (1例)**：电子元件 ref=沸 local=平 — 单日涨8.8%但累计跌幅深，状态机尚未追上
- **2档偏差 (5例)**：石油能源/IT服务/互联网电商 ref=沸 local=温；金属/房地产 ref=凉 local=温
- **1档偏差 (19例)**：多为 ref=平 local=温（12例），温/平边界附近
