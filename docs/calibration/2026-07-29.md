## 2. 校准前基线（旧算法）

| 指标 | 07-21 | 07-28 |
|---|---|---|
| 温度完全一致率 | 18.6% | 5.7% |
| 温度 ±1 档率 | 74.3% | 68.6% |
| 温度方向偏差 | 系统性偏冷 1-2 档（-1档 36 个、-2档 16 个） | 同左（-1档 42、-2档 21） |
| RS MAE / 中位 | 30.2 / 32 | 34.7 / 33 |

RS 偏差的结构性证据：硬科技类（半导体/电子元件/通信设备，07-21 见顶后暴跌）本地 RS 83-99 而参考 1-38；
消费类（白酒/旅游/美容护理）本地 9-39 而参考 70-97。方向不是平移而是**响应速度**：
旧 IBD 口径（0.4·r63+0.2·r126+0.2·r189+0.2·r252）在板块趋势反转 1 个月后仍维持高 RS，与参考"强度"（近 3 月趋势响应快）相反。

## 3. 温度：连续方向分 + 阈值重定

### 3.1 结构性问题（先验成立，非纯拟合）

旧方向分为二值（close>MA60 且 MA20≥MA60 → ±25/±12.5 分）。案例：银行 SW_801780 于 2026-07-21，
close=3905.99 仅低于 MA60(3912.17) **0.16%**，方向分 -25 → 总分 -25.9 → 寒档；参考值为 温。
价格贴 MA 时 0.1% 的距离让总分摆动 50 分——这既是被参考数据证伪的偏差源，也是用户日常看到的温度抖动源。

### 3.2 新公式

```
dir_raw = clip(close/MA60 - 1, ±5%)/5% × 0.7 + clip(MA20/MA60 - 1, ±3%)/3% × 0.3   # [-1,1] 连续
score   = dir_raw × 20 + weighted_roc(20/60/120, 各封顶±30%) × 0.7 + vol_adj(dir_raw × 8, ATR 扩张时)
分档    = 沸 ≥50 / 热 ≥25 / 温 ≥3 / 平 (-19,3) / 凉 (-50,-19] / 寒 (-80,-50] / 冻 ≤-80
```

阈值由 140 样本网格搜索得出（目标：完全一致 + 0.5×相邻档）。状态机（相邻转移、沸/冻 3 日缓冲）不变。

### 3.3 拟合结果（实验脚本 `scripts/exp_calib_fit.py` / `exp_calib_fit2.py`）

| 方案 | 完全一致 | ±1 档 |
|---|---|---|
| 旧公式 + 旧阈值 | 12.1% | 71.4% |
| 旧公式 + 阈值重定 | 60.7% | 98.6% |
| **连续方向 + 阈值重定（采用）** | **70.0%** | **100%** |

方向权重小网格（20/25/30 × roc 0.7/1.0）差异 <1.5pt，取 dir_w=20 / roc_w=0.7。

**全量重建后实测**（`scripts/calib_compare.py`，含状态机全历史一致化）：

| 日期 | 温度完全一致 | ±1 档 | RS MAE / 中位 |
|---|---|---|---|
| 07-21 | **68.6%**（旧 18.6%） | **100%**（旧 74.3%） | **13.5 / 12**（旧 30.2 / 32） |
| 07-28 | **71.4%**（旧 5.7%） | **100%**（旧 68.6%） | **11.0 / 9**（旧 34.7 / 33） |

残留偏差全部为 +1 档偏热（20-22 个品种），无偏冷、无 ≥2 档偏差。

## 4. RS：快窗口口径

| 候选（交易日窗口×权重） | MAE | 中位 | Spearman |
|---|---|---|---|
| 旧 IBD：0.4·r63+0.2·r126+0.2·r189+0.2·r252 | 32.4 | 32.5 | +0.098 |
| 0.7·r63+0.3·r126 | 25.3 | 20.0 | +0.376 |
| 纯 r63 | 23.6 | 18.0 | +0.460 |
| 0.4·r21+0.3·r63+0.2·r126+0.1·r252 | 19.1 | 15.0 | +0.618 |
| 0.5·r10+0.3·r21+0.2·r63 | 12.3 | 9.0 | +0.835 |
| **0.4·r10+0.3·r21+0.2·r63+0.1·r126（采用）** | **12.2** | **9.0** | **+0.836** |

采用 4 窗口版（保留 126 日长尾巴，比 3 窗口版抗单周噪声略稳；两者指标几乎相同）。

注意：RS 语义从"IBD 12 个月相对强度"变为"近 1 个月为主的相对强度"，排名分组（按 node_type）不变。
指数池仅 7 个品种，RS 只能取 {1,17,33,50,66,82,99}（上证50 持续 RS=1 为 2025 下半年科技牛市中
权重指数持续跑输的正确结果，非 bug）。

## 5. 参考系统内部关系（旁证）

参考温度 × 参考强度（140 样本）：凉 均值 34.5 / 寒 15.0 / 平 77.7 / 温 93.8 / 热 100。
强度是快变量、温度与强度强相关但区间重叠（平 38-100），二者是相关但独立的维度，与我们的结构一致。

## 6. 过拟合风险与缓解

- 样本仅 2 个截面 × 70 品种，且两日市场同向（7 月下跌周）。阈值只动了分档边界与方向分连续化，
  没有引入新因子；方向权重取网格平坦区中值。
- 后续每拿到一张新的趋势动物截面图，跑 `python scripts/calib_compare.py <新reference.csv>` 复核
  完全一致率/±1 档率/RS MAE 是否保持；若衰减到基线附近再议二次校准。
